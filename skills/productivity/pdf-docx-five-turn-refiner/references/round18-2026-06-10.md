## Fix Implemented

Changed `qa_failure_score()` scoring for visual changed fraction:

```python
if changed_frac >= 0.25:
    pts = 24
    reasons.append({"type": "visual_changed_fraction_extreme", ...})
elif changed_frac >= 0.20:
    pts = 12
    reasons.append({"type": "visual_changed_fraction_high", ...})
elif changed_frac >= 0.16:
    pts = 6
```

This keeps minor pixel drift as a warning, but prevents a visually poor dense-text fallback from being labelled `ok`.
