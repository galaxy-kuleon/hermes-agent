### 3. Table geometry threshold status

QA now computes:

```json
"table_geometry_status": {
  "ok": true,
  "bbox_tolerance": 0.18,
  "violations": []
}
```

Violation types:

```text
table_count_delta
rows_cols_drift
bbox_norm_delta
page_count_delta handled separately for q7 threshold reasons
```

Control tolerance:

```bash
--table-bbox-tolerance 0.18
```

Smoke runner supports:

```bash
--strict-table-geometry
```

which fails on `table_geometry_status.ok == false` for the core compact/table sample.

### 4. Threshold-triggered q7

Added to `qa`, `refine`, and `convert`:

```bash
--judge-q7-on-threshold
--visual-rmse-threshold 55
--table-bbox-tolerance 0.18
```

Cheap QA first computes contact sheet metrics/table geometry/page count. If thresholds are crossed, q7 is invoked automatically; otherwise no q7 call is made.

Reports include:

```json
"q7_threshold_policy": {
  "enabled": true,
  "visual_rmse_threshold": 55.0,
  "table_bbox_tolerance": 0.18,
  "triggered": true,
  "reasons": [...]
}
```

If triggered, q7 report marks:

```json
"q7_judge_policy": {"trigger": "threshold"}
```
