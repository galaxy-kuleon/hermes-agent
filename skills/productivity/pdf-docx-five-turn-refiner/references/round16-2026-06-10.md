## Problem

The fallback was appended near the document end. Inspection of the DOCX paragraph stream showed explicit page/section breaks very early:

```text
p0  ''
p1  'Designs Form D1'
p2  'Important notes'
p3  BR 'is for electronic filing only.  must be digitally signed.'
p11 SECT ''
p28 SECT ''
p46 'Complete editable source text fallback...'
```

Because the recovered text began after page/section breaks, source page 1 remained visually sparse. The rendered page 1 still used only ~20% of source page height after compacting.

## Fix Implemented

Added page-aware first-page inline recovery in `scripts/pdfdocx5.py`.

New helpers:

```python
def source_pdf_lines_by_page(pdf, max_pages=0) -> list[list[str]]
def first_breakish_paragraph(doc) -> paragraph | None
def insert_paragraph_before(ref_p, text, font_size=4.5, bold=False)
```

Updated `append_missing_source_text()`:

- If low coverage triggers complete fallback mode, source page 1 lines are inserted before the first explicit page/section break.
- Remaining fallback appendix is suppressed when page-1 inline recovery is active, to avoid unnecessary page-count blowup.
- Recovery mode is now reported as:

```text
page1_inline_plus_remaining_fallback
```
