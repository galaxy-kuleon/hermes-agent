## Implemented

### 1. Human visual QA contact sheets

Added CLI flag:

```bash
--contact-sheet
```

Available on:

```text
qa
refine
convert
```

The contact sheet renders selected source PDF pages and rendered DOCX pages, then writes a side-by-side PNG:

```json
"contact_sheet": "/path/to/contact_sheet.png"
```

It uses the same page selector as q7:

```text
--judge-pages sample
--judge-pages risk
--judge-pages all
--judge-pages 1,3-5
```

This lets a human reviewer quickly inspect visual deltas without invoking q7.

### 2. Final-turn q7 patch budget handling

Previously, if q7 produced `fix_suggestions` on the final requested turn, they were recorded but not acted on. The refine loop now supports this policy:

```text
if apply_q7_suggestions is enabled
and q7 returns suggestions on the final requested turn
and turn < 5
then apply one deterministic q7 patch
and run immediate post-patch QA
```

The report records:

```json
q7_patch_report
post_q7_patch_qa
```

This preserves the five-turn cap while avoiding discarded final-turn suggestions.

## Notes

- The contact sheet is intentionally not a substitute for q7; it is a cheap human-review artifact.
- The default regression smoke avoids q7 and XB SDK to stay fast and deterministic.
- Use `--include-xb` only when validating slower OCR paths.
- Final-turn q7 patch handling is implemented in the control flow, but whether it triggers depends on q7 actually returning suggestions on that turn.
