### 2. q7 Judge Schema Normalization

`q7_compare()` now returns both:

```json
parsed
normalized
```

Normalization repairs common q7 schema drift:

- boolean `human_acceptability` → enum
- verbose `manual_rework` → `none | minutes | hours | rebuild_from_scratch`
- missing/non-list defects/top_differences → empty lists with warnings

### 3. q7 Multi-Page Sampling

Added:

```bash
--judge-pages sample
--judge-pages all
--judge-pages 1,3-5
```

The implementation renders selected pages individually with `pdftocairo -f N -l N`, avoiding full rasterization of long PDFs just for VLM judging.

### 4. max-pages QA Subset Fix

When conversion uses `--max-pages N`, the helper now creates `qa_source_subset.pdf` for QA/refinement so page-count comparisons are against the same bounded source. This avoids misleading reports such as converting 3 pages of an 80-page PDF and reporting `page_count_delta = -75`.

### 5. Conservative Duplicate Paragraph Patch

Added opt-in:

```bash
--dedupe-paragraphs
```

It removes exact normalized repeated candidate paragraphs only when source text evidence suggests that paragraph appears fewer times in the source. It is intentionally off by default.

## New Pitfalls / Findings

1. GLM-OCR SDK is more structured but not a magic bullet. It still looped on the Docling OCR test, though less severely than direct `/api/generate`.
2. One-page scanned OCR via SDK took ~81s. For many pages, default `--ocr-engine auto` is safer than forcing SDK for everything without page limits.
3. `--max-pages` must carry into QA. Fixed by generating `qa_source_subset.pdf`.
4. pdf2docx can expand 3 source pages into 5 rendered pages after LibreOffice. This gives us a concrete XC target: page compression / spacing / section repair.

## Next Targets

2. Add structured page-risk selection instead of only first/middle/last: choose pages with table density, low text coverage, images, or page-count drift.
3. Add native table QA: compare table count/rough dimensions from PyMuPDF/pdfplumber evidence against DOCX `w:tbl`.
4. Promote SDK output JSON parsing: use region labels/bboxes, not only Markdown.
