## Problem

`pdf2docx` emits many overlap warnings on HK registered-design forms:

```text
[WARNING] Ignore Line "Application for registration of designs" due to overlap
[WARNING] Ignore Line "Use of Personal data" due to overlap
[WARNING] Ignore Line "Any of the information provided may be made available for public inspection" due to overlap
...
```

The result preserves some native tables but loses large editable text regions. Table parity alone is therefore not enough.

## Fix Implemented

Added optional missing-text recovery to `scripts/pdfdocx5.py`:

```bash
--recover-missing-text
```

New helpers:

```python
def docx_visible_text(doc: Document) -> str

def source_pdf_lines(pdf: Path, max_pages: int = 0) -> list[str]

def append_missing_source_text(candidate, out_docx, pdf, ...) -> dict

def failure_has_text_coverage_issue(score_obj) -> bool
```

Refinement loop behavior:

1. Run normal QA.
2. If `failure_score` contains `editable_text_coverage_low|medium` and `--recover-missing-text` is enabled, create `turn_N_recovered.docx`.
3. If source/candidate coverage is very low, append a compact **complete editable source text fallback** rather than only absent lines.
4. Continue refinement from the recovered DOCX.

Also fixed recovery interaction with compact profiles: recovered turns are now preserved instead of being reset to the original candidate on the next compact pass.

Auto battle now enables recovery for XA cases:

```python
cmd += ["--compact-on-overflow", "--normalize-tables", "--recover-missing-text"]
```
