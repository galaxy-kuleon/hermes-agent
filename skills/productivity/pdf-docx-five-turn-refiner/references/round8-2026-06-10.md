## Implemented

### 1. Mock q7 final-turn injection in `refine`

Added CLI flag:

```bash
--mock-q7-report mock-q7.json
```

Available on:

```text
convert
refine
```

This allows offline control-flow testing without live q7. A mock report may be:

```json
{
  "fix_suggestions": [
    {"patch_type": "table_col_width", "target": "all native tables", "risk": "low"}
  ]
}
```

or a normal nested q7 report:

```json
{
  "q7_judges": [
    {"normalized": {"fix_suggestions": [...]}}
  ]
}
```

When used with:

```bash
--apply-q7-suggestions --turns 2 --mock-q7-report mock-q7.json
```

and the mock suggestion lands on the final requested turn while `turn < 5`, `refine` now applies the deterministic patch and immediately records:

```json
"post_q7_patch_qa": {...}
```

This tests the true final-turn control path, not just standalone `apply-suggestions`.

### 2. Table bbox overlays on contact sheets

Contact sheets now overlay detected table bounding boxes:

```text
red     = source PDF table bbox
orange  = before DOCX rendered table bbox
blue    = after/rendered DOCX table bbox
```

For two-column QA:

```text
Source PDF | Rendered DOCX
```

For three-column compare:

```text
Source PDF | Before DOCX | After DOCX
```

This makes table drift visible without reading JSON.

4. The multi-PDF trend check creates a foundation for detecting regressions across varied PDFs, but it needs a larger corpus before being meaningful.
